# TRPO_Kursvaya_rabota

**DiskAnalyzer** — настольное приложение для анализа использования дискового пространства файловой системой. Программа позволяет исследовать содержимое выбранного каталога, определять размеры файлов, формировать статистику и визуализировать распределение занимаемого пространства в виде круговой диаграммы и таблицы.

Проект разработан на C++17 с использованием Qt для создания графического интерфейса.

## Цель проекта

Разработать оконное приложение для анализа дискового пространства, которое предоставляет пользователю наглядную информацию о распределении размеров файлов между каталогами и категориями файлов.

Программа должна поддерживать различные уровни детализации статистики, отображать абсолютные значения и относительные доли, а также предоставлять результаты в табличной и графической формах.

## Функциональные возможности

### Работа с каталогами

- Выбор каталога через стандартный диалог операционной системы.
- Просмотр непосредственных подкаталогов выбранного каталога.
- Переход в выбранный подкаталог.
- Возврат в родительский каталог.
- Анализ содержимого выбранного каталога с рекурсивным обходом вложенных каталогов.

### Анализ дискового пространства

Программа собирает сведения о размерах файлов и формирует статистику по двум направлениям:

1. **По подкаталогам** — распределение размера файлов между непосредственными подкаталогами выбранного каталога. Файлы, расположенные непосредственно в выбранном каталоге, учитываются отдельно в строке «Файлы в корне».
2. **По категориям файлов** — распределение размера файлов по их типам.

При анализе учитываются размеры файлов в байтах. Для удобства пользователя размеры выводятся в более подходящих единицах измерения.

### Категоризация файлов

Файлы распределяются по категориям на основании расширений.

Предусмотрены следующие категории:

- Изображения.
- Видео.
- Документы.
- Архивы.
- Прочие файлы.

Файлы без расширения и файлы, расширения которых не относятся к предусмотренным категориям, учитываются в категории «Прочие файлы».

### Визуализация результатов

Результаты анализа отображаются в двух формах:

- **Круговая диаграмма** — показывает распределение занимаемого пространства между элементами выбранной статистики.
- **Таблица** — содержит название элемента, размер и долю от общего размера файлов в процентах.

Для повышения читаемости диаграммы предусмотрены легенда и объединение небольших элементов в категорию «Другое». Это позволяет уменьшить количество мелких секторов и избежать наложения подписей.

### Переключение режимов статистики

Пользователь может переключаться между статистикой по подкаталогам и статистикой по категориям файлов.

После завершения анализа переключение режима использует уже собранные данные и не требует повторного обхода файловой системы.

## Работа с приложением

### 1. Выбор каталога

Нажмите кнопку выбора каталога и укажите директорию, которую необходимо проанализировать.

В поле пути отображается текущий каталог. Список подкаталогов позволяет перейти к исследованию отдельной части файловой системы.

### 2. Навигация

Для перехода в подкаталог выберите его в списке. Для возврата на уровень выше используйте кнопку перехода к родительскому каталогу. При переходе между уровнями анализ запускается автоматически

### 3. Запуск анализа

Нажмите кнопку анализа. Программа рекурсивно обходит содержимое выбранного каталога и собирает сведения о размерах файлов. На период анализа приложение перестает откликаться на события.

По завершении анализа отображается общий размер найденных файлов.

### 4. Просмотр статистики

В списке режимов выберите нужный вариант:

- «По подкаталогам»;
- «По категориям файлов».

Таблица и круговая диаграмма отображают результаты выбранного режима.

В таблице представлены названия элементов, занимаемые ими размеры и процентные доли. На диаграмме мелкие элементы могут объединяться в сектор «Другое».

## Алгоритм анализа

Анализ файловой системы выполняется рекурсивно.

1. Программа получает содержимое текущего каталога.
2. Для каждого найденного файла определяется его размер.
3. Размер файла прибавляется к общему размеру всех найденных файлов.
4. Размер файла прибавляется к статистике по непосредственным подкаталогам и статистике по категориям файлов.
5. Для вложенных каталогов выполняется рекурсивный вызов процедуры обхода.
6. После завершения обхода собранные данные используются для построения таблицы и диаграммы.

Символические ссылки не обходятся рекурсивно, чтобы избежать повторного прохода по одним и тем же каталогам и потенциальных циклов.

### Расчёт относительных долей

Доля элемента определяется как отношение его размера к общему размеру найденных файлов, выраженное в процентах.

Если общий размер равен нулю, деление не выполняется. Это позволяет корректно обрабатывать пустые каталоги и отсутствие файлов с положительным размером.

## Ограничения

- Категория файла определяется по его расширению.
- Символические ссылки не обходятся.
- Категория «Другое» на диаграмме объединяет небольшие элементы статистики и не является отдельной категорией файлов.
